# OverSummoned Desk (Fable build)

Smudge lives above your taskbar. Every key you press is one swing of his stamp,
one tug on his line, one turn of his pick or one push of his shovel.

## Run it
1. Install Godot 4.3 or newer (standard build).
2. Import `project.godot`, then press F5.

## Controls
- Type or left-click anywhere on the scene: Smudge works.
- Click Smudge: open his ledger (Places, Heroes, Bag, Smudge, Settings).
- Right-drag: move the window. Drag the ledger by its title.
- Settings: Test mode makes everything 20x faster. Demo typing types for you.

## What is in it
- 9 places, 4 trades (Summoning, Fishing, Lockpicking, Digging), unlocked by skill level.
- 36 heroes as cards, each with a true fact on its label. Shadows until summoned. Duplicates raise the card level.
- 440 items, including the era gear sets and the rift treasure from the neon decades. Hover anything in the Bag or a place's Loot list for its label and odds.
- A rift crate after every 30 minutes of real typing.
- Every number comes from `rules.json`, the same file the website uses.

## Limits of this build
- Each computer links once, with its own code (codes are random, single-use and last ten minutes). On Steam no code will be needed.
- Link it to your account once, either way: in the pet's Settings press Link in browser and say Yes on the website, or on oversummoned.com open Account, press Link a desktop pet, and type the code into the pet's Settings tab. After that it loads and saves the same ledger as the website every time it starts, and the server rolls every find and summon.
- Not linked, it is a stand-alone game saved on this PC.
- The pet is for farming by typing. Crew, expeditions, the bench, gear and the city are on the website, on the same ledger.
- No Windows .exe yet: run it from the Godot editor.
- Keys are counted while Smudge's window has focus. Counting in other apps needs a small Windows add-on that comes later.
- Progress is saved on this PC only.
